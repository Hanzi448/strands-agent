# The agent framework. `backend/agents/` imports it; `backend/tools/` must
# not, so a Lambda that only mutates data can install without it.
# AgentCore packages land with the deploy step.
#
# The `bidi` extra is the voice layer: `BidiNovaSonicModel` needs
# `aws-sdk-bedrock-runtime` and the smithy stack, which the base package
# leaves out. `BidiAgent` itself does not, so `agents/voice.py` imports
# the Sonic model at call time and everything else here installs and
# tests without it.
#
# Capped at the minor everything is tested against: 1.55 renames
# `BidiNovaSonicModel` to `BedrockNovaSonicModel`
# (`strands/experimental/bidi/models/bedrock.py`), and a floating floor
# let a rebuild pick it up the day it shipped -- the deployed runtime
# then refused every call with ImportError (2026-09-14). Adopt the
# rename as its own change, with the local venv upgraded alongside.
strands-agents[bidi]>=1.54,<1.55
